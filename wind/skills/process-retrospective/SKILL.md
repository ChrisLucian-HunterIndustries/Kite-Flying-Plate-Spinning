# Process Retrospective

Single loop fixes the work. Double loop questions the rules that produced the work.

## Lenses
| Lens | Question |
|---|---|
| Lean | Which waste showed up (waiting, rework, extra features)? |
| Agile | Did we deliver working software in small increments with feedback? |
| Systems Thinking | Which feedback loop or incentive caused the problem? |
| Safety | Where could a mistake have reached production unnoticed? |
| Security | Did the process skip any security check? |
| Continuous Improvement | What one rule change prevents this next time? |

## Steps
1. Answer each lens in one line.
2. Choose at most one or two rule changes.
3. Edit AGENTS.md (or the matching wind file) to encode them.
4. Remove any rule that did not earn its keep.
